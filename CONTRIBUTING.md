# Contributing

Read and follow [AGENTS.md](AGENTS.md) and the instructions in
[directives/](directives/). Record human decisions and observations only in
[HITL.md](HITL.md) and [HITL/](HITL/), as those governance files require.

Before standards-related work, read [STANDARDS.md](STANDARDS.md). Before
implementation, architecture, dependencies, build tooling, or development
workflow changes, read and complete [SPECS.md](SPECS.md). Follow
[DESIGN.md](DESIGN.md) for branding work.

To register an issuer, verifier or other entity in the Credimi test
federation, follow [registry/README.md](registry/README.md): a pull request
adding one file to `registry/`, checked automatically by the **Registry**
workflow.
